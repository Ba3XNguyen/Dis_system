# Tài liệu đối chiếu

Nguồn chính là ba PDF của học phần do bạn cung cấp: slide chương2, đề lý thuyết chương2 và đề thực hành chương2 bản đầy đủ17trang. Bộ code được viết lại theo mục tiêu bài lab, không phải tải nguyên project của giảng viên.

Nguồn kỹ thuật chính thức dùng để kiểm tra cách gọi API/lệnh:

- Socket.IO, khởi tạo server: https://socket.io/docs/v4/server-initialization/
- Socket.IO, khởi tạo client và dùng `io()` cùng origin: https://socket.io/docs/v4/client-initialization/
- Socket.IO, client bundle do server phục vụ: https://socket.io/docs/v4/server-options/#serveclient
- RabbitMQ, RPC Java tutorial: https://www.rabbitmq.com/tutorials/tutorial-six-java
- RabbitMQ, queues: https://www.rabbitmq.com/docs/queues
- VideoLAN, HTTP streaming: https://docs.videolan.me/vlc-user/desktop/3.0/en/advanced/streaming/stream_over_http.html
- VideoLAN, UDP streaming: https://docs.videolan.me/vlc-user/desktop/3.0/en/advanced/streaming/stream_over_udp.html
- Linux man-pages, NetEm: https://man7.org/linux/man-pages/man8/tc-netem.8.html
- Linux man-pages, listen: https://man7.org/linux/man-pages/man2/listen.2.html

Không xem số liệu mô tả/ảnh dự kiến trong hướng dẫn là kết quả đã đo. Các phiên bản được chọn để triển khai bài học, không tuyên bố là phiên bản mới nhất.
